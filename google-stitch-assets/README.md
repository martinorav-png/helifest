# HELI Festival — Google Stitch Assets

This folder contains the material to upload or attach when testing the HELI Festival website concept in Google Stitch.

## Included assets

- `HELI-Festival-2026-osalejate-ettepanek.pdf` — event and visual brief
- `figjam-Sisend.png` — project inputs, concept and design direction
- `figjam-Insp.png` — visual and interaction references
- `figjam-Flow.png` — visitor, venue and admin flow notes
- `current-homepage-reference.png` — approved 1280 px-wide homepage screengrab and primary digital visual reference
- `HELI-FESTIVAL-BRIEF-TEXT.md` — text-only transcription of the 16-page PDF for tools that cannot accept PDF attachments
- `../assets/StackSansNotch-VariableFont_wght.ttf` — mandatory custom display font; upload or include this file in the generated project
- `STITCH_PROMPT.md` — ready-to-paste generation prompt

## Suggested use

1. Attach `HELI-FESTIVAL-BRIEF-TEXT.md`, the three FigJam exports, `current-homepage-reference.png`, and the supplied Stack Sans Notch font from `../assets/StackSansNotch-VariableFont_wght.ttf` to Google Stitch. Attach the PDF too only when the tool supports it.
2. Open `STITCH_PROMPT.md` and paste the full prompt into the request.
3. Ask Stitch to generate the seven additional desktop screens and their mobile states. The homepage screenshot is a reference and should not be redesigned.
4. Review the programme, mobile layout, venue pages and transport flow first.
5. Treat the generated result as a visual prototype for the later WordPress theme, not as the final CMS implementation.

## Important

The PDF and FigJam files are reference material. The actual artists, venues, programme and transport details still need to be confirmed by the client before launch.
